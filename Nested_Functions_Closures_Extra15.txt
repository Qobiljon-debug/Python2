Дополнительные задачи на Nested Functions и Closures

--------------------------------------------------

12. Приветствие по времени суток

Создайте функцию time_greeting(name, period).

Она возвращает функцию, которая приветствует человека по имени
в зависимости от времени суток.

Ввод:
morning
Aziz

Вывод:
Good morning, Aziz!

--------------------------------------------------

13. История вызовов

Создайте функцию logger().

Она возвращает функцию log(message).
Каждый вызов сохраняет сообщение, а также возвращает всю историю.

Ввод:
"start"
"process"
"end"

Вывод:
['start']
['start', 'process']
['start', 'process', 'end']

--------------------------------------------------

14. Конвертер температур

Создайте функцию temperature_converter(scale).

Она возвращает функцию для перевода температуры.
Если scale == "C" — из Цельсия в Фаренгейт.
Если scale == "F" — из Фаренгейта в Цельсий.

Формула C→F: (C * 9/5) + 32
Формула F→C: (F - 32) * 5/9

Ввод:
C
100

Вывод:
212.0

--------------------------------------------------

Ввод:

min=5, max=5
min=2, max=5
min=2, max=8
min=1, max=8

17. Степенная последовательность

Создайте функцию power_sequence(base).

next_power()
next_power()

4
8
16

18. Персональный приветчик

Создайте функцию personal_greeter(greeting_word).

приветствие + имя. При первом обращении к имени добавляет "(new)".

Alice

19. Ограничитель значений (Clamp)

Создайте функцию clamp(min_val, max_val).

Она возвращает функцию apply(n).
Если n < min_val — возвращает min_val.
Если n > max_val — возвращает max_val.
Иначе возвращает n.

Ввод:
0 100
-5
50
120

Вывод:
0
50
100

22. Кэш (Memoization)

Создайте функцию memoize(func).

Она возвращает обёртку, которая кэширует результаты.
При повторном вызове с тем же аргументом возвращает кэшированный результат
и выводит "from cache".

Ввод:
square(4)
square(4)
square(7)

Вывод:
16
16 (from cache)
49

Объяснение:
def square(x): return x * x
cached_square = memoize(square)

--------------------------------------------------

23. Цепочка скидок

Создайте функцию price(initial).

Она возвращает функцию apply_discount(percent).
Скидка применяется к текущей (уже изменённой) цене.
Каждый вызов возвращает актуальную цену.

Ввод:
1000
10
20

Вывод:
900.0
720.0

Объяснение:
p = price(1000)
p(10)  → 1000 - 10% = 900
p(20)  → 900  - 20% = 720

25. Таймер обратного отсчёта

Создайте функцию countdown(start).

Она возвращает функцию tick().
Каждый вызов уменьшает счётчик на 1.
Когда счётчик достигает 0 — выводит "Time is up!".

Ввод:
3

Вызовы:
tick()
tick()
tick()
tick()

Вывод:
3
2
1
Time is up!

26. Многоуровневый банк (повышенная сложность)

Создайте функцию bank(owner, balance).

Она возвращает три функции:
- deposit(amount)
- withdraw(amount)
- history()

deposit и withdraw — изменяют баланс и записывают операцию в историю.
history() — выводит все операции.

Ввод:
"Ali" 2000

deposit(1000)
withdraw(500)
withdraw(5000)
history()

Вывод:
Balance: 3000
Balance: 2500
Not enough money
Ali: +1000, -500
